3. **System integration** — ensure flawless frontend ↔ backend communication
4. **Docker optimization** — improve container configuration, environment setup, volume mounting

## DVD Identification Strategy (Core Mission)
The system must achieve **fully automated, accurate DVD naming** without user intervention. The identification pipeline:

1. **Label Detection** (highest confidence) — parse disc label cleanly for direct matches
2. **Ollama LLM Agent** — propose title/year from label text when unclear
3. **Whisper Audio/Subtitle Analysis** — extract character names and plot hints via transcription
4. **OpenSubtitles Verification** — download guessed subtitles to cross-validate correctness
5. **Web Search Iteration** — search for characters/plot elements from transcript until confident match found
6. **Fallback Conservative Naming** — use robust LLM naming if all else fails (avoid false positives)

**Context**: DVD labels are often poor quality; Blu-rays slightly better. The system should never ask for user input — always iterate through these methods until success or timeout.

## Known Constraints & Fixes
- SearxNG search preference can be bypassed in escalation logic; ensure `WebSearcher.search_web` is used
- Windows MakeMKV reliability: write output to local Windows path first, then copy to WSL temp (avoid direct UNC paths)
- WSL identify edge case: for generic labels like `DVD_VIDEO`, don't skip Pass 1/2 if MKV filename contains usable title hints
- Runtime DB settings override compose env defaults; verify effective settings from `/api/settings` endpoint when debugging path mismatches
